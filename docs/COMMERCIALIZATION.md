# CLIO 상업화 체크리스트

제품 방향에 대한 의사결정 기록. 코드가 아닌 사업 준비 항목을 추적합니다.

## 포지셔닝 (흔들리면 안 되는 것)

**"로컬 프라이버시 + 한국 대학원생 워크플로우(Notion 연동, 한글 OCR)"**가 무기.
NotebookLM, Zotero+AI가 못 주는 것에 집중하고, 범용 기능 확장으로 강점을 흐리지 않는다.

## 과금 모델 (초기)

- **무료 로컬 티어**: Ollama 기반 전체 기능. 서버 비용 0원이므로 지속 가능.
- **BYOK(Bring Your Own Key)**: Claude/Gemini 등 사용자 본인 키. 과금·정산 책임이 없어
  사업자 부담 최소화. → 초기에는 이 구조 유지.
- 자체 서버/크레딧 판매는 결제 시스템 + 정산 + 세금 + 약관이 전부 따라오므로
  유료 전환 수요가 검증된 뒤에 도입.

## 법적 준비 (유료화 전 필수)

- [ ] **사업자등록** — 개인사업자(간이과세)로 시작 가능. 홈택스에서 무료.
- [ ] **통신판매업 신고** — 온라인 판매 시 필요. 지자체/정부24, 등록면허세 수만 원 수준.
      간이과세자는 면제 조항 확인.
- [ ] **이용약관** — 책임 한계(AI 답변의 정확성 비보장), 환불 규정 포함.
- [ ] **개인정보처리방침** — `docs/PRIVACY_POLICY.md` 초안 참고. 유료화/회원가입 도입 시
      개인정보보호법상 고지 의무 발생. 로컬 우선 구조라 처리하는 개인정보가 거의 없다는 게
      가장 강력한 방어 — 이 상태를 유지하는 것 자체가 전략.
- [ ] **학교 규정 확인** — 학부생 창업 관련 교내 규정/지원 프로그램(창업지원단) 확인.
