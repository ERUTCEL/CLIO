# CLIO 개인정보처리방침 (초안)

> ⚠️ 이 문서는 초안입니다. 유료 서비스 개시 전 법률 검토를 거쳐 확정하고,
> 앱 내와 배포 페이지에 게시해야 합니다.

시행일: (미정)

## 1. 기본 원칙 — 로컬 우선

CLIO는 로컬 우선(local-first) 애플리케이션입니다. 사용자가 추가한 논문 PDF,
메모, 인덱싱 데이터(임베딩, 검색 데이터베이스), 대화 내용은 **모두 사용자 기기에만
저장되며, 개발자 서버로 전송되지 않습니다.** CLIO는 자체 서버를 운영하지 않습니다.

## 2. 기기 외부로 나가는 데이터

다음 경우에만 데이터가 기기 외부로 전송됩니다.

| 경우 | 전송 대상 | 전송 내용 |
|------|----------|----------|
| 클라우드 AI 사용 시 (사용자가 API 키 등록) | Anthropic / OpenAI / Google / Groq | 질문 및 관련 문서 발췌 (해당 업체 개인정보처리방침 적용) |
| Notion 연동 시 (사용자가 토큰 등록) | Notion API | 사용자가 연결한 데이터베이스 읽기 |
| 논문 메타데이터 조회 | CrossRef API | 논문 DOI |
| 임베딩/OCR 모델 최초 다운로드 | Hugging Face | 모델 파일 요청 (사용자 문서 아님) |
| 자동 업데이트 확인 | GitHub | 앱 버전 정보 |

Ollama(로컬 AI)만 사용하는 경우 사용자 문서는 어떤 외부 서버로도 전송되지 않습니다.

## 3. API 키 보관

사용자가 등록한 API 키는 운영체제의 암호화 저장소(macOS Keychain / Windows DPAPI)로
암호화되어 기기에만 저장됩니다.

## 4. 수집하지 않는 것

- 회원가입, 계정, 이메일 등 식별 정보를 수집하지 않습니다.
- 사용 통계, 행동 분석(analytics)을 수집하지 않습니다.
- 크래시 리포팅은 기본 비활성이며, 활성화되더라도 오류 스택 정보만 전송하고
  문서 내용·개인 식별 정보는 포함하지 않습니다.
