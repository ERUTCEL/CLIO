# PDF 필기노트

PDF 위에 자유롭게 손글씨·타이핑을 하고, **교수님 말씀을 입력하면 AI가 해당 위치에 바로 형광펜과 메모를 달아주는** 개인용 필기 앱입니다.
CLIO와는 별개의 독립 앱이며, 백엔드 없이 브라우저에서 동작합니다.

## 실행

```bash
cd pdf-notes
npm install
npm run dev        # http://localhost:5180
```

빌드: `npm run build` → `dist/` (정적 파일이라 어디든 올려서 쓸 수 있습니다)

## 기능

| 도구 | 단축키 | 설명 |
|------|-------|------|
| ✋ 이동/선택 | V | 스크롤, 텍스트 상자 편집·이동 |
| ✒️ 펜 | P | 자유 필기 (마우스·펜·터치, 스타일러스 지원) |
| 🖍 형광펜 | H | 반투명 형광펜. Shift를 누르면 수평으로 |
| 🧽 지우개 | E | 지나간 획/형광펜 지우기 |
| T 타이핑 | T | 클릭한 위치에 텍스트 상자 생성 (한글 OK) |

### 타이핑 (스캔본·이미지 PDF 포함)

- 글자가 없는 **스캔본/이미지 PDF**에도 어디든 타이핑할 수 있습니다
- ✋ 이동 모드에서 **더블클릭**하면 그 자리에 바로 타이핑
- 텍스트 상자 위에 마우스를 올리면 나오는 막대: ⠿ 이동, **A− / A+** 글자 크기, **B** 굵게, **▭ 흰 배경**(스캔된 글자를 가리고 그 위에 쓰기), × 삭제
- 상자 오른쪽 끝을 끌면 폭 조절, Esc로 입력 마치기. 새 상자는 마지막에 쓴 스타일을 이어받습니다
- **사진·이미지(JPG/PNG 등)**도 바로 열 수 있고, 여러 장을 고르면 한 노트로 묶입니다

- 실행 취소/다시 실행: Ctrl/⌘+Z, Ctrl/⌘+Shift+Z
- **펜만** 체크: 손바닥·손가락 터치는 무시하고 펜으로만 필기 (태블릿용)
- 필기는 브라우저(IndexedDB)에 자동 저장되고, 첫 화면 "최근 문서"에서 다시 열 수 있습니다
- **필기 포함 PDF 저장**: 필기를 입힌 PDF로 내보내기
- **노트 .md**: 메모·할 일·교수님 말씀·페이지별 필기를 Markdown으로 내보내기

### AI 교수님 말씀

1. 오른쪽 패널 **AI 설정**에 Anthropic API 키 입력 (모델: Opus 5.5 / Sonnet 5.5 / Haiku 5.5)
2. 교수님 말씀을 타이핑하거나 **🎙 받아쓰기**(Chrome/Edge)로 받아 적기
3. 범위 선택 (현재 페이지 / 앞뒤 2쪽 / 문서 전체) → **PDF에 바로 적용**

AI가 해당 페이지 텍스트에서 말씀이 가리키는 문장을 찾아

- 중요 → 노란 형광펜, 수정 필요 → 빨간 밑줄, 참고 → 파랑, 아이디어 → 초록, 질문 → 분홍
- 여백에 짧은 필기 메모
- 교수님이 시킨 일은 **할 일** 탭에 자동 추가

를 넣습니다. 기록에서 **필기 지우기**로 그 말씀으로 생긴 필기만 되돌릴 수 있고, Ctrl+Z도 됩니다.

## 참고

- API 키는 이 브라우저의 localStorage에만 저장되고 `api.anthropic.com`으로만 전송됩니다. 공용 PC에서는 사용 후 지워 주세요.
- 스캔본 PDF(텍스트가 없는 페이지)는 AI에게 페이지 이미지를 보내서 위치를 찾습니다. 텍스트 PDF보다 위치가 조금 덜 정확할 수 있고, 한 번에 최대 20쪽까지 보냅니다.
- 받아쓰기는 브라우저의 Web Speech API를 사용합니다 (Chrome/Edge 지원, Safari 일부).
